# homebrew

Homebrew tap for various tools

## Installation

To install packages from this tap, first add the tap to your Homebrew installation:

```bash
brew tap leninmehedy/homebrew
```

## Available Formulas

### trackpad

Trackpad utility tool.

```bash
brew install leninmehedy/homebrew/trackpad
```

Or after tapping:

```bash
brew install trackpad
```

## Usage

For more information about a specific formula, use:

```bash
brew info trackpad
```

## Contributing

To add more formulas to this tap, create a new `.rb` file in the `Formula/` directory following the Homebrew formula format.
